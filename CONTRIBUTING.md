# Contributing

Thanks for your interest in Zed-i18n! Issues and pull requests are welcome.
Here are a few things to keep in mind.

## Language

Please write pull request titles, commit messages, and code comments in English where possible.
They don't need to be perfect.

## License

- Content derived from Zed (`catalog/`, `manifest/`, and `translations/`) is licensed under [GPL-3.0](LICENSE).
- Everything else, including the tools, tests, prompts, and docs, is licensed under [MIT](LICENSE-MIT).

By opening a pull request, you agree that your contribution is released under the license that applies to the files you changed.

## Translation fixes

When you change a translation, please mention in the pull request how it was reviewed:

- Reviewed by a native speaker, or
- Produced with an AI tool (please name the model)

Either is fine. It just helps me know how carefully to review the change.

## New languages

If you'd like to add a new language, please open an issue first so we can discuss it before you start.

That's it. Thanks again!
